# Cluster O/P — Mobility and Pain/Return-to-Loading for Strength & Combat Sport

## Scope
This layer supports strength, gymnastics, BJJ and MMA programming. It is not a diagnostic or treatment system. It helps the engine identify a performance-limiting movement constraint, choose a low-cost corrective route, preserve pain-free training, and know when to refer out.

## Core source-derived principles

1. Movement screening and clinical assessment are different jobs. A screen can establish a movement baseline and identify painful or deficient patterns, while diagnosis belongs to qualified healthcare assessment.
2. Pain changes the decision route. A painful pattern should not be treated as a normal performance problem to "push through" with more exercise.
3. Corrective work should start from a baseline, target the most relevant limiting category, and use test/retest rather than accumulating generic drills.
4. Mobility, stability/motor control, and movement-pattern retraining are distinct categories. Range availability should be sufficient before asking the athlete to solve the same position only with more stability or complexity.
5. Mobility prescriptions should be task-specific. Overhead, press, hang, squat, pistol and lunge positions have different range demands.
6. Corrective/mobility work is supplemental. It should not displace the athlete's primary strength or sport exposure.

## Product routing

### No pain, no named mobility limitation
No corrective block. Use normal warm-up and full-ROM strength work.

### Named mobility goal or performance-limiting range
Identify the exact position. Choose a proxy test. Use strength through range, loaded end range, active mobility or targeted positional/stretching work. Retest the same position.

### Stable local pain with no red flags
Do not diagnose. Find the provocative task and the highest useful tolerable version. Regress load, ROM, leverage, assistance, velocity, volume or frequency. Preserve unaffected regions and the healthy side. Monitor next-day response.

### Red flags / major functional change
Stop affected loading and recommend qualified assessment.

## High-value task maps

### Squat / takedown / landing
Ankle dorsiflexion, hip flexion/rotation, adductor capacity, trunk control at depth.

### Overhead / HSPU / handstand
Shoulder flexion/external rotation, elbow extension, thoracic/ribcage organization, wrist tolerance, active overhead strength.

### Hang / pull-up / muscle-up
Overhead position, scapular control, elbow/wrist tolerance, shoulder/lat range where relevant.

### Press / dip / push-up
Shoulder extension/internal-rotation demands, scapular control, elbow/wrist tolerance, ROM scaling when needed.

### BJJ / MMA
Hip rotation, adductor capacity, ankle/foot positions, thoracic rotation, shoulder overhead/extension based on the athlete's actual game. Do not chase extreme range without a task reason.

## QA rules

* Never claim a screen diagnoses an injury.
* Never add generic mobility to a clean athlete just because the library contains drills.
* Every mobility row must name the goal position it supports.
* Every pain modification must state the current tolerable route and a path back toward specificity.
* If the same intervention fails repeated test/retest, change the intervention or refer out rather than adding more volume.
