## Problem

### Your goals do not exist in isolation.

A heavy BJJ week changes how much lifting you can recover from. A +45 kg weighted pull-up is not the same programming problem as five bodyweight reps. Training in a park changes exercise selection. Pain changes what you can load today without automatically deleting the goal.

Most workout generators collect a few answers and produce a template.

This system is built to make those details change the program.
