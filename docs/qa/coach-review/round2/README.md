## מה כדאי לבדוק

1. **קליסתניקס:** האם ההיררכיה מתוקנת לגמרי? האם הקפיצות ב־weighted pull-up נכונות (מעבר לבנצ'מרק הסט מתקצר בחזרה)? האם ההתקדמות במאסל־אפ היא מה שהתכוונת?
2. **היבריד:** האם ה־OAP עכשיו "more total clean reps" כמו שביקשת?
3. **טריאתלטית:** האם הלו"ז ברור עכשיו?
4. **ציון מ־10 לכל אחת.**

## ידוע ופתוח

- **טריאתלטית: כפילות בהערה.** "Your scheduled Thursday ride." מופיע פעמיים. זה כבר תוקן בקוד, אבל התוכנית הזו נבנתה לפני התיקון.
- **היבריד, שבוע 3:** בשני של שבוע 3 נשאר רק סט ה־OAP הקצר (2×1). זה פחות משבוע 2. המנוע עצמו בונה 2×2 ועוד 3×1, ושלב מאוחר יותר הוריד את הסט העליון. עדיין לא מצאתי איזה שלב.
- **טריאתלטית: אימון חזרה למרוץ.** עדיין אין בריק עם מעברים בשבועות 1–2. השאלה מסבב 1 פתוחה: איך היית בונה את זה עם היסטוריית האכילס?
- **אחרי ההשקה**, לפי מה שסימנת:
  - צפיפות הסשן של הנער
  - אוטורגולציה לקפיצות חוזרות אצל הכדורסלן
  - ימים רצופים במאסטרס
