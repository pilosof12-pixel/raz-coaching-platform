# ביקורת מאמן: 7 תוכניות מהארכיטקטורה החדשה

## מה השתנה

עד היום המודל כתב את כל 4 השבועות. עכשיו המודל כותב **רק את שבוע 1**, כלומר את ההחלטות המקצועיות: בחירת תרגילים, ימים, סדר, מינון ונקודות דגש. **שבועות 2–4 נבנים אוטומטית** לפי כללי פרוגרשן. כל תוכנית עוברת אחר כך את כל בדיקות האיכות כרגיל.

כללי הפרוגרשן של שבועות 2–4:

| סוג שורה | כלל |
|---|---|
| כוח עם משקל ידוע (עד 6 חזרות) | פרוגרשן יחיד על המשקל, בערך +2.5% ואז +5%. לעולם לא מעל מה שהמקסימום של המתאמן מאפשר לאותן חזרות ו־RPE |
| היפרטרופיה (6–15 חזרות) | דאבל פרוגרשן: קודם חזרות (שבוע 2), אחר כך משקל (שבוע 3) |
| סקיל של המטרה | קודם סט נוסף, אחר כך חזרה או זמן החזקה. שבוע 4 שומר על הסטנדרט של שבוע 3 |
| הרמת תחרות (סנאץ'/C&J) | לפי אחוז מהמקסימום: כ־85% בשבוע 2, ו־88–90% בשבוע 3 |
| פריימר כוח מתפרץ | לכל היותר סט אחד נוסף, בלי לטחון |
| אקססוריז | צעד קטן בחזרות או בזמן החזקה |
| סיבולת רציפה | בערך 10% בשבוע על מנוף אחד. ריצה ארוכה נשארת "ריצה ארוכה" |
| אינטרוולים | חזרה אחת נוספת בשבוע, באותו קצב |
| תרגיל עזר שאינו מטרה | נשאר במינון של שבוע 1. ההתקדמות הולכת למטרות |
| שבוע 4 | קונסולידציה: פחות עבודה בלי למחוק את מה שהושג |
| פלטו שהמתאמן מדווח עליו | דרופ סט בסט האחרון להיפרטרופיה (למשל תאומים). קלאסטר 2+2+1 במשקל של דאבל מקסימלי לכוח (למשל צ'ין־אפס) |

בלוק שמסתיים בתחרות (שבוע תחרות, שבוע קרב, מרוץ) ממשיך להיכתב כולו על ידי המודל.

## מה חשוב לבדוק

1. **שבועות 2–4:** האם הפרוגרשן נשמע כמו מאמן? האם הקפיצות נכונות, ושבוע 4 נכון?
2. **תרגילי עזר שנשארים קבועים:** האם נכון שרק המטרות מתקדמות, או שיש תרגילים שהיית מקדם?
3. **ההערות בשבועות 2–4:** הן קצרות וכלליות יותר מההערות של שבוע 1, שהמודל כתב. האם זה מורגש? האם זה מוריד מהציון?
4. **הסדר באימון:** סקיל או פריימר, אחר כך כוח, ואז היפרטרופיה ואקססוריז.
5. **ציון מ־10 לכל תוכנית,** עם הממצאים העיקריים.

## פריטים פתוחים שאנחנו יודעים עליהם

- **טריאתלטית:** אין בשבועות 1–2 אימון חזרה גנרלית על המרוץ (2 מקצועות או יותר עם 3 מעברים או יותר). במנוע אין כלל שבונה את זה לטריאתלון. בגלל היסטוריית האכילס זו החלטה מקצועית: איך היית בונה את זה?
- **אינטנסיפיירים לפלטו:** אף אחד מ־7 המתאמנים לא דיווח על פלטו, ולכן הכלל לא מופיע בתוכניות האלה. הוא נבדק בטסטים.
