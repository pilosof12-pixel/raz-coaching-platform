Week 1 puts the two primaries together on Mon and Fri, keeps the straight-arm work away from back-to-back days, and makes Saturday intentionally low-cost so Monday’s heavy pull stays fresh.

If the old medial-elbow ache shows up after straight-arm work, trim in this default order: Tue Band-Assisted Straddle Planche, Sat Advanced Tuck Planche, Tue Advanced Tuck Planche, Tue Advanced Tuck Front Lever, then Fri Strict Muscle-up back-off singles, Fri Weighted Pull-up +25 kg, and Mon Weighted Pull-up +30 kg last. If symptoms instead follow bent-arm pulling, trim Wed Ring Row first, then Tue Advanced Tuck Front Lever, then Fri Weighted Pull-up +25 kg 4x4, and touch Mon Weighted Pull-up +30 kg 3x3 only if it still persists. That order is only the default: if one named row clearly reproduces the ache and an earlier row does not, reduce the row that reproduces it first and leave the asymptomatic one alone. If recovery slips with no pain yet, same load feels harder, sleep worsens, warm-ups feel slow, trim Fri Weighted Pull-up +25 kg 4x4 to 3 sets before you change the heavy Monday pull.

On Weighted pull-up with 40 kg for 3: this block holds it at a maintenance dose rather than developing it, on purpose. Strict muscle-up on rings for 5 clean reps and Freestanding handstand push-up are what this block develops. Keeping the exposure protects what you already have and keeps it ready to progress in the next block; it is not an attempt to improve it in these four weeks.
