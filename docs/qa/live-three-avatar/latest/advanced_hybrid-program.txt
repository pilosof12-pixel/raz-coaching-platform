Compact block: primary work stays protected for Back Squat and One-Arm Pull-up, with strict Overhead Press held at a recoverable build-week dose submaximally and one weekly long run preserving your marathon pathway without stealing from MMA. Friday is intentionally low-cost/recovery-contingent because gym + MMA already fills all 7 days.

Weeks 2-4: only increase when Week 1 lands inside the target RPE with clean reps. Squat load nudges up first, strict One-Arm Pull-up set count stays stable while rep quality/assistance improves, press volume stays modest, and Week 4 consolidates the best quality with slightly less fatigue.

Pain/substitutions: if elbows or biceps tendon feel cranky, keep strict One-Arm Pull-up crisp and cut Assisted One-Arm Pull-up reps before cutting the strict singles; if Friday fatigue is high after MMA, remove the final accessory first. If a lift causes sharp pain, stop that exercise and swap only to the nearest listed supported pattern you can do pain-free that day while keeping the main goal exposures.
