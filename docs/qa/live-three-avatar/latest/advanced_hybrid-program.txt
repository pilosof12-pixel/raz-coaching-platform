Priority stays on squat and One-Arm Pull-up quality, with OHP progressed at a recoverable dose and marathon work kept to one real weekly run so MMA quality stays intact. Friday is intentionally low-cost; if MMA fatigue is high, cut the final accessory there first.

Weeks 2-4: add load only if the prior week stayed inside the target RPE with clean reps. One-Arm Pull-up progression comes from cleaner singles and less assistance, not from piling on extra strict sets. The long run progresses by small distance bumps only.

If elbows get cranky, keep strict One-Arm Pull-up reps very clean and reduce assistance-demand before reducing ROM; if shoulders feel beat up, swap Push Press for Dumbbell Shoulder Press at the same RPE; if knees/hips feel unusually heavy from MMA, keep Friday Back Squat at the low end of the load range and preserve bar speed.
