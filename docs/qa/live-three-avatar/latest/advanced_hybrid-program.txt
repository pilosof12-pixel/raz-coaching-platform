Built around your real week: protect squat and One-Arm Pull-up quality first, keep strict overhead work meaningful but compact, and keep marathon work to one genuine easy long run so MMA recovery stays intact. Friday is intentionally low-cost because gym + MMA already fills all 7 days.

Weeks 2-4: only the smallest useful levers move. Squat load rises conservatively if bar speed/RPE stay honest, One-Arm Pull-up volume/assistance tightens slightly, strict OHP stays submaximal and only progresses when readiness supports it, and the long run builds gradually before a lighter Week 4 consolidation.

If elbows or biceps tendon feel beat up, keep the strict One-Arm Pull-up singles crisp and cut 1 set from Weighted Chin-up before touching the direct One-Arm Pull-up rows. If knees/hips are unusually fatigued from MMA, keep Friday Back Squat at the listed RPE cap or trim the final accessory first. For the run, keep it easy enough to nose-breathe or speak in short sentences; if shin/Achilles soreness appears, hold the prior week’s distance instead of pushing up.
