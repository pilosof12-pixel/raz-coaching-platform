Primary work stays concentrated on Back Squat and strict One-Arm Pull-up, with OHP moving at a smaller dose and one weekly easy long run preserved around MMA. Friday’s gym work is intentionally low-cost and recovery-contingent.

Weeks 2-3 build by one small lever at a time: heavy squat load, One-Arm Pull-up execution or assistance, and long-run distance while pace stays easy. Week 4 trims accessory and back-off volume and shortens the long run so you finish fresher while keeping moderate intensity on the main lifts.

If elbows or medial forearms get cranky, keep strict One-Arm Pull-up to clean singles, add assistance on Assisted One-Arm Pull-up, and hold Chin-up at the last painless added load. If Friday’s long run or same-day MMA leaves your legs flat, shorten the long run to the fallback in the note and cut Friday Back Squat to 1 set before changing Monday’s heavy squat.
