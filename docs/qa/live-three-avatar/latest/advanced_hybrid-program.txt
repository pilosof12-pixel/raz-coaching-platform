This block keeps Back Squat and One-Arm Pull-up protected first, gives Overhead Press compact weekly work, trims nonessential push fatigue to fit MMA, and keeps the long run on Thursday so it does not crowd the Monday squat/One-Arm Pull-up session.

Weeks 2-3 only move up if Week 1 stays inside the RPE caps: squat load climbs a small step, One-Arm Pull-up improves through cleaner doubles/singles and slightly less assistance rather than more hard volume, strict press nudges up inside the same compact set cap, and the long run is held at the tolerated dose gradually. Week 4 keeps the best standards, drops accessory fatigue, and cuts the long run back.

If elbows or forearms flare, keep Monday One-Arm Pull-up to singles only and use a touch more assistance on Tuesday. If shoulders are beat up from MMA, keep Push Press crisp and repeat the last successful Overhead Press load rather than forcing the next jump. If knees or hips are beat up, stop Friday Back Squat after 2 sets or repeat the prior load before changing Monday. If the run starts beating up your legs, repeat the last tolerated distance instead of forcing the next increase.
