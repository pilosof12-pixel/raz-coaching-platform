Main work stays pointed at squat and One-Arm Pull-up while keeping strict overhead work moving and the marathon goal alive with one recoverable long run each week. Friday is intentionally low-cost because MMA already fills all 7 days.

Weeks 2-4: add small load or volume only where quality stays solid. One-Arm Pull-up strict work progresses by one clean single/cluster rep per arm before chasing fatigue; assisted work progresses by slightly less assistance or an extra clean rep. The long run builds gradually, then consolidates in week 4.

If elbows or biceps tendon get cranky on unilateral pulling, keep the strict reps cleaner and cut one set before changing the exercise. If shoulders feel beat up from MMA, keep Push Press smooth and submaximal. If knees or low back are unusually fatigued, keep Friday Back Squat at the lower end of the load note and drop the final accessory first.
