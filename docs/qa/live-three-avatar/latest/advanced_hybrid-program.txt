Built to protect the squat and One-Arm Pull-up priorities around the MMA week. Monday carries the highest-skill/heaviest work, Friday stays deliberately low-cost, and the marathon side quest stays at one easy long run per week so it supports rather than steals from the primary goals.

Weeks 2-3 progress the main lifts and One-Arm Pull-up quality while keeping most support work stable. Week 4 consolidates with fewer back-off and accessory sets while holding moderate intensity, so you finish fresher without losing momentum.

If elbows or forearms get cranky, keep Monday One-Arm Pull-up to singles only, add assistance on Tuesday, and repeat the last clean week. If Friday MMA leaves the legs flat, stop the Friday Back Squat after the first set. If the long run starts harming sport quality, trim 2-4 km from the run before cutting any primary lifting.

On Marathon: this block holds it at a maintenance dose rather than developing it, on purpose. 220kg back squat and 100kg overhead press are what this block develops, and 5 sport sessions a week already own most of the recovery budget. Keeping the exposure protects what you already have and keeps it ready to progress in the next block; it is not an attempt to improve it in these four weeks.
