Primary work stays compact so your squat and One-Arm Pull-up quality survive the MMA week. Tuesday’s run preserves your current direct running frequency and is your easy long-run anchor for the marathon goal, while staying clearly secondary to strength and skill.

Weeks 2-4: progress the smallest useful lever. Squat and OHP nudge load or set count only if Week 1 lands inside target effort. One-Arm Pull-up progresses via a little more clean single volume or slightly less assistance, not by grinding. The long run progresses only by a small distance increase through Week 3 at the same easy effort, then consolidates in Week 4.

If elbows or biceps tendon get irritated on unilateral pulling, first reduce assistance demand or total One-Arm Pull-up sets before touching squat or OHP. If knees or low back feel beat up from MMA, keep Back Squat technique strict and cut the optional Friday accessory first. Keep the run easy; if impact niggles rise, shorten distance that week rather than forcing pace.
