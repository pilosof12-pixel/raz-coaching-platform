Keep the main freshness for Back Squat and One-Arm Pull-up, with overhead work progressing but still submaximal around the MMA load. Friday is intentionally the low-cost session; if Friday MMA is especially taxing, drop the final accessory first.

Weeks 2-4: squat and strict press progress mainly by small load or set additions if bar speed and recovery stay on plan; One-Arm Pull-up progresses by a little more clean unilateral work or slightly less assistance; the run progresses only by long-run distance while keeping the effort easy.

Pain/substitutions: if elbows or forearms flare, keep strict One-Arm Pull-up singles crisp and cut 1-2 reps before reducing quality, then use a bit more help on Assisted One-Arm Pull-up. If shoulders feel beat up from MMA, keep Push Press lighter and preserve the direct Overhead Press day. If knee or hip fatigue is high, keep both Back Squat exposures but reduce the accessory leg work before touching the squat rows.
