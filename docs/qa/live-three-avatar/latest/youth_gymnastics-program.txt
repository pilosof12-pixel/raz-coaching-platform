Skills come first every session: fresh bar muscle-up practice, fresh handstand entries, then support strength. Keep everything crisp and submaximal, stop a set or skill block early if speed, line, or turnover quality drops.

Weeks 2-4: the main progressions are less assistance and a little more clean bar-muscle-up practice, more controlled handstand attempts with the same calm entry standard, and small rep/hold increases on support work. Week 4 keeps the best Week 3 standards but trims fatigue.

No pain is reported, so use the plan as written. If wrists, elbows, or shoulders get sore, first reduce handstand or transition attempts by 1 set, then switch to the easier band/assist that still keeps clean mechanics. For bar muscle-up work, never force ugly turnovers; for handstands, stop after repeated missed kick-ups.
