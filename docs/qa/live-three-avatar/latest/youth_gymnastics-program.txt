Skills stay first while you are fresh. Session A is more bar-muscle-up focused, and Session B puts a little more attention on handstand balance and lower-body athleticism.

Weeks 2-4: Week 2 makes the main skill step-up by using less help on the straight-bar turnover and slightly more handstand control. Week 3 holds that skill standard on purpose and builds the support underneath it. Week 4 trims fatigue but keeps the best clean standards you earned.

If you get sharp or local wrist, elbow, shoulder, or knee pain, stop that row right away. For handstands, shorten the set or use the wall sooner; for straight-bar turnover work, add bench or band help back immediately; for pistols, reduce depth to the cleanest pain-free range and keep control slow.
