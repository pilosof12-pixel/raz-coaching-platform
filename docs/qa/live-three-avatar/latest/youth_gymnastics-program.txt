Skills stay first each session: bar muscle-up practice and handstand balance work while you’re fresh, then support strength. Stop skill sets early if timing, pull height, or balance clearly drops off.

Weeks 2-4: the plan progresses by adding a little more clean bar-muscle-up practice first, then reducing band help once turnover stays fast and symmetrical. Handstand work progresses through more controlled kick-up attempts and brief balance saves, while Week 4 keeps the best Week 3 standard with slightly less total fatigue.

If wrists, elbows, or shoulders get sore, stop the painful set, add a bit more band help on Bar Muscle-up Transition Drill, reduce kick-up attempts, and use the wall-supported Handstand Hold only in a pain-free range. No repeated failed muscle-up attempts.
