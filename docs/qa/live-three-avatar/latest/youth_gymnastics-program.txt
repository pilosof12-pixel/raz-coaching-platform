Skills come first each session while you’re fresh. Keep every rep and attempt clean, stop before form drops, and avoid repeated misses.

Weeks 2-4: the plan progresses by improving handstand entry quality and wall-control time, and by moving bar muscle-up work from clean assisted singles toward cleaner doubles or lighter assistance. Support strength uses small rep increases only when technique stays solid.

If wrists, elbows, or shoulders get sore, cut the final support row first, then reduce skill attempts by 1 set while keeping only successful-quality reps. If a bar muscle-up transition gets asymmetrical or slow, use more band help that day. If kick-ups turn into repeated bail-outs, stop the set and reset.
