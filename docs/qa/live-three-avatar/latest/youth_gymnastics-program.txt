Skills stay first while you’re fresh. We’ll practice bar-specific muscle-up turnover every week, pair it with an explosive pull, and keep handstand work focused on clean kick-ups plus enough wall time to build line and shoulder capacity.

Weeks 2-4: the main progressions are cleaner/lighter-assisted Bar Muscle-up Transition Drill reps, a few more high-quality kick-up attempts, and small hold/rep upgrades on support work. Week 4 keeps the best Week 3 skill standard but trims fatigue.

If wrists, elbows, or shoulders get sore, stop the set when line or turnover quality drops. For handstands, reduce the kick-up height and use more wall contact. For bar muscle-up work, use more band help or more foot help from the bench so every rep stays smooth and symmetrical.
