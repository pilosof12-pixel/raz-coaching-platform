Keep the lifting crisp so the key run work stays high quality. The 3K interval day is the main driver, the ruck progresses one lever at a time, and pull-up work stays frequent but submaximal enough to build rather than just test.

Weeks 2-4: if paces and loads land within the listed RPE and you feel normal the next day, take the planned progression. If shin irritation, unusual foot/ankle soreness, or interval pace collapses show up, first hold the newest running or ruck progression and drop the optional support work before touching the main lifts.

If shin symptoms return, shorten the easy runs by 10-15 minutes and hold the ruck at the last symptom-free week. If elbows or shoulders get cranky on pull-ups, keep the same exercise but stop 1-2 reps earlier on each set.
