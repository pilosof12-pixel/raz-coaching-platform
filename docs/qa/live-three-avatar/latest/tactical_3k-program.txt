Primary focus stays on the 3K: one specific interval run each week, two easy runs to preserve your tolerated run frequency, one direct 20 kg ruck, and three real strength sessions spaced out so you keep strength and pull-up progress without crowding recovery.

Weeks 2-4: the main 3K progression moves from longer race-specific reps, then more sustained reps, then a lower-volume faster expression week. Ruck progresses by pace first while load stays 20 kg. Pull-up progress comes from one heavy weighted exposure plus two bodyweight exposures spaced apart.

If shin discomfort rises beyond mild awareness, first hold or reduce the newest run or ruck pace progression and keep the easy runs truly easy. If a lift feels off, keep the same exercise and trim load 2.5-5% while staying inside the RPE target.

Weekly running volume anchor: your established, tolerated baseline is about 18-20 km per week across 3 running exposures, and this block keeps 3 running exposures while quality becomes more 3K-specific. Easy-run durations are set at or slightly below that baseline on purpose, so the new interval specificity is the only impact variable stepping up. While shins and next-day soreness stay normal, rebuild toward the top of your 18-20 km range by adding a few minutes to the easy runs first, never by adding a fourth running day or by making the easy runs faster. If shin symptoms return, cut easy-run duration first, hold the newest interval and ruck progression, and repeat the last symptom-free week before progressing again.
