Keep the key work sharp: one race-specific run, one direct ruck, three real strength exposures, and pull-up work spaced across the week. Easy running stays truly easy so the Tuesday quality session drives the block.

Weeks 2-4: running progresses by one main lever at a time, ruck pace tightens while load stays 20 kg, pull-up work builds mostly through rep quality/volume before a lighter Week 4 expression. If any main lift or pull-up set overshoots the target RPE or gets sloppy, hold that week’s load next time instead of forcing progression.

If shin discomfort returns above mild awareness, first shorten the Saturday easy run by 10-15 minutes and hold the next ruck pace progression; if symptoms persist, replace the Saturday run with an equally easy Bike session for the same duration that week and keep Tuesday interval pace conservative.
