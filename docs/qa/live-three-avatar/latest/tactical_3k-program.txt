Built around your current tolerated 3-run + 1-ruck pattern, with the 3 gym sessions supporting the 3K first, then ruck pace and pull-up progress. The main build is: one specific interval run, two genuinely easy runs, one weekly 20 kg ruck, and three concise full-body strength sessions that maintain squat/deadlift strength while pushing pulling performance.

Weeks 2-4: progress the smallest useful lever at a time. The interval run progresses by volume first, then pace, then a lower-volume faster expression in Week 4. The ruck progresses mainly by distance first, then a shorter brisker Week 4. Strength work mostly uses small load/rep progressions while keeping fatigue controlled.

If shin irritation returns above mild “background” level, first shorten the easy runs by 5-10 minutes and keep the interval pace honest rather than forcing faster splits. If rucking lights up shins/feet, keep load at 20 kg and reduce distance before changing pace. For strength, swap Push-up for Overhead Press if wrists/shoulders dislike floor pushing, and swap Reverse Lunge for Bulgarian Split Squat if knee comfort is better with the rear foot elevated.
