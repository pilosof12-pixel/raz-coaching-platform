This block runs straight into Day 0: Week 1 and 2 realize race fitness, Week 3 tapers, and Week 4 is competition week. Back Squat and pulling stay on minimum effective dose while the Thursday Hyrox-specific session carries the primary progression. After Hyrox, the next two weeks for the half should be recovery-first, then one controlled longer easy run plus one light pace touch; this block is peaking Hyrox, not both races.

Weeks 2-4: the Monday easy run extends once in Week 2, then comes back down; the Thursday Hyrox session grows from a 6-part partial rehearsal to an 8-part race-order rehearsal in Week 2, then shrinks to a sharper reduced-volume tune-up in Week 3. Week 4 keeps rhythm and race-speed feel while volume descends session to session so you arrive fresh.

If the left Achilles grumbles, change the run stressor that likely caused it: if it flares after the Thursday Hyrox session, replace Monday’s Run with Rower for the same duration at easy effort; if it starts on Monday, shorten Monday first and keep Thursday’s station loads while capping the run reps. Keep calf work, keep pain at 2/10 or less, and do not add a second separate run day.
