This block runs into the event, now about 4 weeks away: the final week is competition week, not another training week. This is the 4-week run-in to Hyrox Day 0: Weeks 1-2 realization, Week 3 taper, Week 4 race week. The main limiter we’re targeting is holding race run pace when you have to run straight off stations. Squat and pulling stay on minimum reliable maintenance. The half marathon stays alive through two direct run touches each week, but this block is not trying to peak both; after Hyrox, the next two weeks need recovery first, then easy run frequency plus one rebuilt long run for the half.

Weeks 2-4: Monday grows into the race-order rehearsal in Week 2, then volume drops while race pace and station feel stay sharp. Back Squat and pulling stay flat on purpose until taper cuts reps, not load. Friday easy running stays at Week 1 on purpose in Week 2 so Monday carries the progression, then comes down so you arrive fresh.

If the left Achilles grumbles, change the next run-based session first: keep the same time or interval structure on Rowing Ergometer, keep calf work easy, and cut the fast run reps before you cut squat work. If wall ball, lunges or burpee broad jump load the calves, trim that station volume before you trim the easy run.
