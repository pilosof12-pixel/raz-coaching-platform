This block runs into the event, now about 4 weeks away: the final week is competition week, not another training week. This is your final 4-week run-in to Hyrox, so the block is built to arrive sharp for the A race rather than to build general fitness. The half marathon stays supported through easy-run durability and not getting wrecked by Hyrox; the two weeks after this block should be recovery first, then a quick return to easy running and one longer run, not another peak.

Week 2 extends the Monday race-order work and only nudges the Friday long run if the Achilles stays quiet. Week 3 is a true taper: less total work, same race-feel intensity. Week 4 is competition week: short touches only, with the last session there to make you feel fast, not tired.

If the left Achilles grumbles, change the most likely running stressor first: trim the Friday run by 20-30% or swap it to Rower for the same time before you cut the specific Hyrox station work. If symptoms show up during Monday race-pace running, keep the stations, drop the next run rep, and hold all remaining run pace no faster than 4:20/km. Stop any session if pain rises past 3/10 or changes your gait.
