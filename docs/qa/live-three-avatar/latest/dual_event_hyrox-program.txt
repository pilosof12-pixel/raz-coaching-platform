This is your 4-week arrival block into Friday’s Hyrox, starting 3.9 weeks out: Weeks 1-2 sharpen race-relevant pace and station feel, Week 3 tapers volume, and Week 4 is competition week. Squat and pulling are held at minimum-effective maintenance on purpose. The half marathon is not being peaked here; the two weeks after Hyrox should rebuild easy running first, then add one controlled longer run and one light pace touch.

Weeks 2-4: only take the Week 2 run extensions if Week 1 pace and next-morning Achilles response were clean. Week 3 keeps the same key loads and pace bands but removes volume. Week 4 keeps the Mon-Fri rhythm as Day -4 to Day -1: one squat touch, one easy run, one short race-feel sharpener, and one optional primer; the Friday sharpener keeps a tiny upper-body strength touch so all four gym days stay true strength sessions.

If the left Achilles grumbles, change the run that most likely caused it. If it shows up after the Friday quality work, keep the easy run and swap the next Friday run row to the Rower at the same work/rest. If it shows up after the longer easy run, cut the next Tuesday duration by 10-15 minutes or use the Rower there, and do not stack make-up running on Wednesday.
