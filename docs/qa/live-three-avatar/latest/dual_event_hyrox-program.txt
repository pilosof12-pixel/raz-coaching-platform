This is the last 4-week runway into your A-race Hyrox: Weeks 1-2 realize race pace and transitions, Week 3 tapers, and Week 4 is competition week built backward from Day 0. Mon-Fri are the four gym days; the Saturday run in Weeks 1-3 stays in so the half-marathon remains alive without stealing the Hyrox peak. After Hyrox, the next two weeks should rebuild easy running and restore one longer easy run again; they should not add more Hyrox-style intensity.

Weeks 2-4 progress by making the race-specific work a little longer and more continuous first, then cutting volume while keeping race pace and competition loads familiar. The squat and pulling work are held at maintenance on purpose.

If the left achilles grumbles, first change the run stressor closest to onset: cut the second tired-run rep, or swap the Saturday Run to Rowing Ergometer for the same time, before you cut squat or pull work. Avoid back-to-back run days, and stop any run rep that changes your stride.
