This is your Weeks -8 to -5 prepeak-specificity build, with race day still about 7.9 to 4.9 weeks away. The aim here is still to build, not taper: keep the two gym sessions supportive, restore your tolerated three nonconsecutive run exposures, and keep the main progression on swim economy plus race-relevant run pace.

Weeks 2-3 add one variable at a time: Monday run intervals add one 500 m rep, Tuesday swim adds 100s, Saturday long run inches up, and Friday squat only nudges if it stays crisp. Week 4 is consolidation: lower nonessential volume, keep the key paces and loads, and finish fresher without losing feel.

If the Achilles stiffens during or the morning after a run, first remove the most recently increased run variable and repeat the last clean week. Keep every run flat, skip hills entirely, and if Monday intervals trigger symptoms reduce that session first before touching Wednesday’s easy run or Saturday’s long run.
