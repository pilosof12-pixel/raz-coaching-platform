This block covers 7.9 to 4.9 weeks before race day, so it is a prepeak specificity build: the triathlon work gets more race-relevant while gym work stays supportive and low-cost enough to protect the sport week. The swim gets the clearest progression because it is the biggest limiter and the cheapest place to gain time; the run progresses carefully inside your current achilles-tolerant pattern of three non-consecutive main run days.

Weeks 2-4: Tuesday’s main swim set builds through Week 3, Friday keeps the second swim technique-led with a small repeat increase, the Monday run interval session progresses one variable at a time, and the brick work becomes slightly more race-specific without adding reckless run volume. Week 4 is a consolidation week: moderate intensity stays in, nonessential volume comes down so you finish fresher, not flat.

If the right achilles stiffens during a run or the next morning after, first repeat the last clean week or reduce the most recently progressed run row here before touching the easy run. Keep every run flat, no hills, and if pain appears mid-session swap that day’s Run row for Bike for the same time cap.
