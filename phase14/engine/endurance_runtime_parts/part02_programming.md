## ARTICLE 5 — VO2max Development and Interval Training

There is no single best HIIT protocol. Select interval structure by desired physiological target, accumulated high-quality work, modality, athlete profile and recovery cost. [LB Chs.1,3-5; K7 Chs.9,11; M8 Ch.21]

Key programming logic:
- Long intervals can facilitate sustained high oxygen uptake but must be paced repeatably enough to preserve multiple quality reps.
- Short intervals can also accumulate high oxygen uptake because recovery is incomplete and VO2 remains elevated across repetitions; they may permit higher external speed/power or a different neuromuscular profile.
- RST/SIT add more glycolytic and neuromuscular stress. They are not automatically superior VO2max tools.
- Time near VO2max can be a useful acute target, but the time needed to reach high VO2 varies by athlete, mode, training status, warm-up and kinetics. Never hard-code one universal interval format or exact required minutes.
- Work intensity, work duration, relief duration/type and accumulated work interact. Recovery must be short enough to support the intended physiological carryover but long enough to preserve the required external output and mechanics.
- Progress one main variable at a time: useful accumulated work, external pace/power, or density only when the physiological target remains intact.
- Do not simultaneously increase intensity, interval duration, density and repetition count.

Decision rules:
IF VO2max development is the target and several-minute work can be repeated well, THEN consider long intervals supporting sustained high oxygen uptake and repeatable output.
IF long reps collapse but shorter bouts remain high-quality while VO2 stays elevated, THEN use short intervals with appropriate incomplete recovery.
IF sport already supplies repeated-sprint/glycolytic stress, THEN prefer a controlled aerobic-power format unless repeated-sprint qualities are independently deficient.
IF physiological target is reached but power/pace/technique collapses early, THEN reduce duration, accumulated work or density rather than adding repetitions.
IF the same session becomes easier at stable quality, THEN progress one variable and reassess response.

Failure modes: universal 4x4/30-30/Tabata; HR-only control of short work; chasing maximal intensity at the expense of accumulated quality; unnecessary SIT when aerobic-power stimulus is desired; adding volume after mechanics/output deteriorate; ignoring hard sport exposure.

Unresolved source gap: no universal exact minutes-at-VO2max threshold required for adaptation.

## ARTICLE 6 — Anaerobic Conditioning and Repeated High-Intensity Performance

Peak sprint ability, glycolytic capacity and repeated-effort recovery are different problems. Repeated high-intensity performance reflects phosphagen availability, glycolytic ATP production, oxidative recovery, neuromuscular output and recovery between efforts. [K7 Chs.2,5,11; LB Chs.2,5,11]

Programming implications:
- Peak speed/power: use enough recovery to preserve near-maximal output; stop before the session becomes metabolic conditioning.
- Repeated-sprint ability: deliberately incomplete recovery is appropriate only when repeatability itself is a real sport/athlete limitation.
- Glycolytic capacity/tolerance: longer or denser high-intensity work can create larger glycolytic stress but carries high fatigue cost and should be used only when justified by sport demands and athlete profile.
- Recovery ability: oxidative development supports PCr resynthesis and repeatability between intense efforts.
- Sprint duration, recovery duration/type, repetition count, direction changes and modality all change the metabolic/neuromuscular target. “6 x sprints” is not a sufficient prescription.
- A high-peak-power athlete with poor repeatability needs a different intervention from an athlete whose peak output is low.
- Combat athletes already receive repeated high-intensity exposure from sparring/drilling; supplementary work should fill a gap rather than imitate hard rounds by default.

Decision rules:
IF maximal sprint speed/power is the target, THEN use full enough recovery and terminate on meaningful quality loss.
IF repeated sprint ability is the target, THEN use short high-output efforts with deliberately incomplete recovery and monitor repeatability.
IF glycolytic capacity is genuinely limiting for sustained hard bursts, THEN use denser/longer high-intensity work sparingly because recovery cost is high.
IF hard sparring already supplies frequent glycolytic/neuromuscular exposure, THEN bias extra conditioning toward missing aerobic/recovery qualities.
IF repeatability improves while peak output remains poor, THEN shift toward strength/speed/power rather than adding more conditioning density.

Unresolved source gap: no universal percentage performance drop for terminating every repeated-sprint session.

## ARTICLE 7 — Programming Endurance Training

A conditioning block is an allocation problem across a finite weekly recovery budget. Training adaptation depends on overload, specificity and recovery; volume and intensity interact. [K7 Chs.9,11,14; M8 Ch.21; LB Chs.8,9]

Block-building sequence:
1. Define target/event: duration, pace/power, burst pattern, technical and mechanical demands.
2. Audit training already present: sport practice, races, hard sparring, lifting and conditioning.
3. Identify the most plausible limiter from available evidence: aerobic base, upper sustainable intensity, VO2max, repeated-sprint ability, peak power, economy or sport-specific execution.
4. Choose the main adaptation emphasis. Secondary qualities may be held nearer maintenance when appropriate; this is a coaching inference, NOT a universal one-quality-only law.
5. Select modality by specificity versus fatigue/mechanical cost.
6. Set the hard-session budget after counting sport practice.
7. Add recoverable low-intensity volume only to the extent useful for the goal.
8. Place priority work when sufficiently fresh.
9. Progress the smallest useful variable and monitor external output plus internal response.
10. Reassess when enough training has accumulated or trends show the current plan is no longer producing the intended adaptation.

Frequency is a way of distributing dose, not an isolated target. No universal weekly frequency is supported. Increase frequency/duration/intensity only when it improves target exposure without degrading quality/recovery. Avoid large simultaneous jumps in all three. Reduce general volume before important competition while preserving enough intensity and specificity.

Intensity distribution: endurance examples are generally low-intensity dominant with smaller high-intensity fractions, and some elite examples are polarized. Do NOT encode 80/20 or polarized/pyramidal distribution as a universal law.

Decision rules:
IF sport practice contains multiple hard days, THEN count them inside the hard-session budget before formal HIIT.
IF the athlete improves and recovers well, THEN progress the smallest useful variable rather than redesigning the block.
IF fatigue trends upward while performance is stable/falling, THEN reduce nonessential volume/local overlap before adding intensity.
IF competition approaches, THEN reduce general volume and increase specificity while preserving performance-relevant intensity.

Unresolved source gaps: no universal weekly volume, hard-session count, intensity-distribution percentage or deload schedule for all athlete types.

## ARTICLE 8 — Concurrent Strength + Endurance Training

Concurrent training is not automatically incompatible. Interference risk is conditional and can reflect accumulated volume, frequency, modality/local overlap, acute fatigue and insufficient recovery. The source literature is conflicting; do not tell athletes cardio automatically kills gains. [LB Ch.6; M8 Ch.22]

Priority-based programming:
- Strength/power priority: protect heavy/explosive work from prior hard conditioning, remove unnecessary endurance volume, and favor lower local-interference modalities where they still achieve the conditioning target.
- Hypertrophy priority: manage local fatigue/energy cost so conditioning does not repeatedly reduce resistance-training volume/load quality.
- Combat priority: sport practice is the primary specific conditioning stimulus; strength and supplemental conditioning should support technical/sparring quality. Add hard intervals only for a defined missing quality.
- Endurance priority: protect key endurance sessions and event-specific volume; use strength supportively at a recoverable dose and trend toward maintenance as competition demands rise.

Order/spacing:
- More recovery between hard overlapping modes can reduce acute interference, but the source does NOT justify one universal six-hour/24-hour rule.
- IF sessions must share a day, perform the current priority quality first unless a specific source/sport constraint justifies otherwise.
- Separate sessions more when both heavily stress the same tissues.
- Easy low-intensity work can generally coexist closer to lifting than hard intervals because acute fatigue cost is lower.
- Running usually has more eccentric lower-body cost than cycling; rowing/swimming can create meaningful upper-body/back fatigue. Think shared tissues, not “cardio minutes.”
- Poor sleep/shift work and high sport volume reduce total recoverable dose even when each isolated session looks reasonable.

Decision rules:
IF strength/power is primary, THEN perform priority lifting fresh and cap conditioning to the dose required by the secondary goal.
IF both modes hard-stress the same muscles, THEN increase recovery or separate them when possible.
IF the conditioning adaptation can be reached by running or cycling and lower-body strength is primary, THEN consider cycling to reduce eccentric cost, unless running specificity is itself required.
IF combat volume rises sharply, THEN reduce supplemental conditioning/nonessential lifting before sport quality deteriorates.
IF endurance is primary, THEN protect key endurance work and use strength as support.

Unresolved source gap: no universal required hours of separation or fixed concurrent weekly dose.
