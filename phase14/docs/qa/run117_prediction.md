# Run #117 — the same athlete, one thing changed

Written before the run. The only difference from run #116 is that the brief now
names what the race is made of. Same avatar, same engine, same model.

Run #116 scored 7.3 (coach) / 7.72 (encoded standard). Its brief was 31,742
characters and never contained "wall ball", "sandbag", "burpee" or "race pace".

## What has to be true if naming it worked

Each of these is checkable, and each is a thing the brief now states outright.

1. **All eight stations appear by the end of Week 2.** SkiErg, Sled Push, Sled
   Pull, Burpee Broad Jump, Row, Farmers Carry, Sandbag Lunge, Wall Ball. Run
   #116 trained four and never mentioned the other four.
2. **At least six of the eight in Week 1.** #116 had two.
3. **SkiErg in Week 1 and Week 2, prescribed against 3:38.** It is the one
   component the athlete gave a number for and it appeared nowhere at all.
4. **A station straight into a run: one pair in Week 1, two in Week 2.** #116
   had one in each, and only in the one direction.
5. **A rehearsal in Week 1 or 2** — four or more components in a single session
   with at least three transitions. #116 had none.
6. **The sled carries a load related to competition**, not "RPE-selected load".

## The number

If the brief lands, event specificity should move from 6.4 toward 8.5 and
conditioning progression from 7.1 toward 8.2, which on the coach's weights gives
roughly **8.3**.

So: **8.0 to 8.6 if the brief works. 7.3 to 7.7 if it is ignored.**

Nine is not the prediction, and it would be dishonest to claim it. The taper
finding he charged 0.45 for -- a week that cuts volume while multiplying jumping
-- now has a check but no repair and no brief, so there is no reason for it to
be fixed this time. Getting past roughly 8.5 needs that one closed too.

## The outcome that would be most useful

A program that still omits stations. That would mean the same thing the Snatch
Pull taught us in run #114: an instruction that reaches the model in full and is
ignored anyway, which sends this to a deterministic repair rather than more
words. The brief is cheap and the repair is not, so it is worth knowing which
one this needs.
